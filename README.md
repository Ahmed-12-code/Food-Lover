# Food Lover (early version)

A restaurant website ("Food Lover") built with HTML and CSS: landing page, menu and table booking page.

<img src="https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white" alt="HTML5" /> <img src="https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white" alt="CSS3" /> 

## Features

- Landing page with the restaurant history, special offers and special menu
- Full menu page
- Book a Table page
- Font Awesome icons

## Run locally

No build step or dependencies.

```bash
git clone https://github.com/Ahmed-12-code/Food-Lover.git
cd Food-Lover
# open index.html in your browser
```
